# Telegram Музыкальный Бот

Этот бот позволяет искать и скачивать музыку с YouTube прямо в Telegram.

## Требования
- Python 3.8 или новее
- Установленный `ffmpeg` (необходим для извлечения аудио с помощью `yt-dlp`)

## Как запустить (Локально)

### 1. Получение токена бота
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям.
3. Скопируйте полученный HTTP API токен.

### 2. Настройка конфигурации (Токен бота)
Бот хранит ваш токен в специальном скрытом файле с названием `.env` (просто точка и три буквы, без имени).
1. Создайте в папке с ботом файл с названием `.env` (или просто скопируйте и переименуйте шаблон `.env.example`).
2. Откройте файл `.env` в любом текстовом редакторе (например, в Блокноте).
3. Замените текст `your_telegram_bot_token_here` на ваш скопированный токен. Файл должен выглядеть примерно так:
   ```
   BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
   ```
4. **Если Telegram заблокирован** в вашей стране (ошибка `Cannot connect to host api.telegram.org` или `Таймаут семафора`), добавьте в этот же файл строку с прокси:
   ```
   PROXY_URL=socks5://user:password@127.0.0.1:1080
   ```

### 3. Установка зависимостей и Запуск

**Важно:** Убедитесь, что у вас установлен `ffmpeg`. Без него извлечение аудио не сработает!
- **Windows**: Скачайте с [официального сайта](https://ffmpeg.org/download.html), распакуйте и добавьте путь к `bin` в системную переменную PATH, либо используйте команду `winget install ffmpeg`.
- **Linux (Ubuntu/Debian)**: `sudo apt update && sudo apt install ffmpeg`
- **macOS**: `brew install ffmpeg`

#### Для пользователей Windows (Автоматически)
Мы подготовили скрипты для быстрого старта без консоли:
1. Дважды кликните по файлу `setup.bat`. Он автоматически создаст виртуальное окружение, установит все зависимости и создаст файл `.env` (если его нет). Дождитесь надписи "Настройка завершена успешно". Эту операцию нужно сделать только один раз.
2. **Обязательно** откройте файл `.env` и вставьте туда токен вашего бота (см. шаг 2).
3. Для ежедневного запуска бота просто дважды кликните по файлу `start.bat`.

#### Для пользователей Linux/macOS (Вручную)
1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```bash
   python main.py
   ```
Если всё настроено верно, в консоли появится сообщение `INFO:root:Starting bot...`.

## Как пользоваться
1. Перейдите в Telegram и откройте чат с вашим ботом.
2. Нажмите кнопку **"Start"** или отправьте команду `/start`.
3. Отправьте боту запрос:
   - **Название песни** (например, `Король и Шут - Кукла колдуна`). В этом случае бот выполнит поиск по **YouTube** и скачает первый результат.
   - **Прямую ссылку** на видео или трек (например, с YouTube, YouTube Music, SoundCloud, TikTok, ВКонтакте и сотен других платформ, поддерживаемых библиотекой `yt-dlp`).
   - **Скачивание отрезка по времени**: Добавьте интервал времени в конце ссылки, чтобы скачать только нужный фрагмент (очень полезно для длинных концертов или миксов, чтобы уложиться в лимит Telegram 50 МБ). Формат: `ссылка ММ:СС-ММ:СС`. Пример: `https://youtube.com/watch?v=... 10:00-15:30`.
4. Подождите несколько секунд, пока бот скачает и обработает аудио.
5. Бот пришлет вам готовый `.mp3` файл, который можно слушать прямо в Telegram!
